# Ушко для Windows

Ассистент совещаний: пишет встречу, расшифровывает речь, различает участников и собирает протокол с поручениями. Всё считается на вашем компьютере, записи наружу не уходят.

## Установка

1. Скачайте **[Ushko-Windows.zip](https://github.com/aldente647-coder/ushko-windows/releases/latest/download/Ushko-Windows.zip)** (94 МБ).
2. Распакуйте архив: правой кнопкой → «Извлечь все».
3. Запустите **Install-Ushko.bat**.
   Если появится синее окно «Windows защитил ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
4. Если Windows спросит разрешение на установку библиотек Microsoft — «Да».
5. Дождитесь загрузки нейросетей (от 3 до 8 ГБ — зависит от компьютера). Оборвался интернет — запустите Install-Ushko.bat ещё раз, загрузка продолжится с того же места. Совсем не качается — включите VPN на время установки.
6. Ушко откроется само. Дальше оно запускается из меню «Пуск» и работает без интернета.

Обновление — так же: скачать архив заново и запустить Install-Ushko.bat. Записи, настройки и скачанные нейросети сохраняются.

## Что нужно

- Windows 10 или 11, 64-битная
- 8 ГБ оперативной памяти, лучше 16
- около 12 ГБ свободного места на диске C

Ушко работает и на старых процессорах: если процессор не поддерживает AVX2, само запускается совместимая версия, а при установке выбирается облегчённая модель распознавания.

## Если что-то не так

- **Нет голоса в записи** — Параметры → Конфиденциальность → Микрофон → разрешить классическим приложениям.
- **Расшифровка не успевает за речью** — Настройки → Транскрипция → выберите модель полегче («Medium» или «Small»).
- **Не работает или закрывается** — запустите **Ushko-Diagnostika.bat** из архива, повторите то, что не работает, и закройте Ушко. На рабочем столе появится `Ushko-otchet.zip` — пришлите его.
- **Скрипт установки показал ошибку** — сфотографируйте окно и пришлите.

Записи лежат в папке «Музыка\ushko-recordings», база и модели — в `%APPDATA%\com.ushko.app`. Удаление: Параметры → Приложения → Ушко.
